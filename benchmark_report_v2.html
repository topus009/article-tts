TTS Benchmark v2

Интерактивный отбор движков — фильтры, сортировка, оценки (сохраняются в браузере)
RTF < 0.5 (очень быстро) 0.5–1.0 (реалтайм) 1.0–3.0 (медленно) > 3.0 (очень медленно) RTF = время генерации / длительность аудио, меньше = лучше
URL или путь, откуда грузить .wav (по умолчанию benchmark_output/). Для GitHub Pages укажи свой CDN/репо.
Как пользоваться (кликни)

Цель: прослушать примеры, поставить оценки ★ (1–5) и отфильтровать лучшие движки для работы.

Оценки и фильтры сохраняются автоматически в localStorage браузера — при повторном открытии всё на месте. Кнопка ↺ Сброс очищает их.

Сортировка: кликни по заголовку любого столбца (Engine, RTF, Gen, …). Повторный клик меняет направление.

Фильтр по оценке: выбери «Оценка ≥ 4» чтобы видеть только хорошие. «Только оценённые» скрывает неоценённые.

Экспорт: кнопка ⬇ Оценки скачает JSON с твоими оценками — чтобы сохранить выбор или перенести.

Аудио: кнопка ▶ в каждом ряду. Тексты — первые абзацы твоих статей (EN и RU).
